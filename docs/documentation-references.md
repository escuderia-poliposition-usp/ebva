# Referências para a estrutura documental

Fontes primárias consultadas em **30/10/2026**. Esta estrutura é uma adaptação
editorial para o EBVA; contratos e exemplos técnicos foram conferidos nas fontes
locais. Parâmetros de outros veículos não foram transplantados.

| Fonte | Aplicação no EBVA |
| --- | --- |
| [ROS 2 Humble](https://docs.ros.org/en/humble/index.html), [fonte oficial do índice](https://github.com/ros2/ros2_documentation/blob/humble/source/index.rst) | Separar instalação, tutoriais progressivos, guias por tarefa, conceitos e referência de pacotes |
| [RoboRacer Build](https://f1tenth.readthedocs.io/en/main/) e [introdução](https://f1tenth.readthedocs.io/en/main/getting_started/intro.html) | Pré-requisitos e percurso de entrada; distinguir material ROS 2 e ROS 1 |
| [RoboRacer Learn](https://f1tenth-coursekit.readthedocs.io/en/latest/) | Encaminhar a plataforma já preparada para exercícios e aprendizagem progressiva |
| [Autoware](https://docs.autoware.org/main/) e [diretrizes de documentação](https://docs.autoware.org/main/contributing/documentation-guidelines/) | Navegar por instalação, arquitetura, integração do veículo, simulação, testes e contribuição |
| [Nav2 Controller, branch Humble](https://github.com/ros-navigation/navigation2/tree/humble/nav2_controller) | README explica responsabilidade/interface e aponta configuração/tutorial especializados |

Esses portais orientam organização, sem declarar compatibilidade do EBVA com
todas as suas versões/componentes. O alvo segue Humble/Ubuntu 22.04/Python 3.10.
