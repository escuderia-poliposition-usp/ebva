# Documentação do EBVA

O [README principal](../README.md) apresenta o projeto e seus 27 pacotes.
A [Wiki](https://github.com/escuderia-poliposition-usp/ebva/wiki) ensina percursos
completos; esta referência acompanha a revisão do código. Para instalações
anteriores, leia os arquivos da revisão instalada: a Wiki acompanha a linha atual.

## Escolher uma leitura

| Sua tarefa | Percurso |
| --- | --- |
| Conhecer o projeto | README principal → arquitetura → README do pacote |
| Preparar uma máquina | Instalação → recursos do pacote → inspeção do perfil |
| Operar uma composição | Operação → autoridade → configuração dos donos |
| Ligar componentes | Interfaces → contrato do produtor/consumidor → testes da ligação |
| Desenvolver e revisar | Contribuir → testes → padrão documental |
| Investigar um problema | Diagnóstico → README do componente → evidência da execução |
